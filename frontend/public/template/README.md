# Template photography

This folder is intentionally empty of photos: they come from the Figma template and could not be downloaded by the build
environment (it had no network access to figma.com). Until you add them, image slots show soft tinted blocks (the layout is unaffected).

Export each layer from Figma (file `4MEkyw099w9nYwTAWBRfca`, page "Visual Design") as JPG/PNG at 2x and save with these names:

| File | Used on | Figma node |
|---|---|---|
| `hero.jpg` | Home hero background | 117:361 |
| `banner.jpg` | Page title banners (Shop, Cart, Checkout…) | 117:541 |
| `range-dining.jpg`, `range-living.jpg`, `range-bedroom.jpg` | "Browse the range" tiles | 117:374, 117:379, 117:384 |
| `inspiration-1.jpg`, `inspiration-2.jpg`, `inspiration-3.jpg` | Inspirations slider | 117:462, 117:474, 117:475 |
| `share-1.jpg` … `share-10.jpg` | "#Furniro" gallery (section hides if `share-1.jpg` is missing) | 117:494 … 117:503 |
| `logo.png` | Header logo mark (optional) | 117:355 |

Product photos are NOT taken from here: they come from each product's images in the admin dashboard.
